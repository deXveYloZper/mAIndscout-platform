# Decisions

Dated notes only. This folder is not a second specification.

- **Gates.** Only the owner declares a gate green: `YYYY-MM-DD-<slice or phase>-gate.md` with the eval command, the
  result, the golden folder and the accepted holes (never a hole for identity keys).
- **Choices.** A non-obvious choice, a new claim type, flag or table (with its schema in `slice0/`), or an exception to a
  rule gets one short note: the decision, why (the owner's words where they gave them), and exactly what it covers.
- Link each note from the component page it changes ([../build/components/](../build/components/)).
